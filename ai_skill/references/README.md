# AI Skill References 说明

本目录存放 AI 执行 single-cell RNA/ATAC batch workflow 时需要的 SOP 级参考。

核心文件：

- `rna_workflow.md`：RNA 单样本和 GSE 批处理 SOP。
- `atac_workflow.md`：ATAC、co-ATAC、longevity ATAC SOP。
- `batch_workflow.md`：discover、status、smoke sample、batch run、audit 顺序。
- `output_contracts.md`：RNA、ATAC、product 输出完整性契约。
- `command_reference.md`：统一 CLI 命令速查。
- `troubleshooting.md`：失败和异常结果排查顺序。
- `reuse_guide.md`：如何迁移到新项目。

不要在这里放原始数据、结果文件、大型对象或隐私 metadata。
