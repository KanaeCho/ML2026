# 结果示例

本目录用于存放经过人工检查、体积较小、可以安全提交到 Git 的示例结果。

不要把完整结果目录放到这里。

允许在人工确认后放入：

- README 或文档中需要展示的小型 PNG 示例图。
- 使用合成数据或脱敏数据制作的小型 CSV 示例。
- 说明真实结果生成位置的 Markdown 说明。

不要提交：

- 完整 `output/` 目录。
- `.h5ad`、`.rds`、`.RData`、`.loom` 文件。
- fragment、FASTQ、BAM 或完整 matrix 文件。
- 未确认可公开的样本 metadata。

完整结果位置请参考 `docs/io_summary.md`，后续会继续补充 `docs/results_index.md`。
