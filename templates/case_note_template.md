# Case Note 模板

## Case ID

例如：`RNA-QC-GSE000000-GSM0000001-2026-05-24`

## 问题类型

例如：QC 异常、聚类异常、注释异常、batch effect、批处理失败、输出缺失、版本混乱。

## 问题现象

具体描述结果中哪里异常。不要只写“结果不好”。

## 涉及数据

- 数据类型：RNA / ATAC / co / longevity / product integration
- 样本：
- 批次或 GSE：
- 分析阶段：QC / 过滤 / 降维 / 聚类 / 投影 / 注释 / 导出 / 批处理

- 脚本：
- notebook：
- 结果图：
- metadata：

- 日志文件：

## 初步判断

列出可能原因，并说明依据。

## 检查顺序

记录实际排查顺序。

1.

## 检查结果

记录每一步发现了什么。

## 尝试处理

记录尝试了哪些调整。没有调整也要写“未调整，仅记录”。

## 是否需要重跑

说明是否需要重新计算，以及重跑范围。

## 当前结论

说明问题是否解决，或当前只能做出什么判断。

## 后续待确认

列出仍不确定的问题。
